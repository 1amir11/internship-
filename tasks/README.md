## Convention for new tasks

```
tasks/task-NN-<slug>/
  README.md          # objective, inputs, outputs, status
  <deliverables>.md  # reports, notes
```

- Zero-padded numbers: `task-02-...`, `task-03-...`
- Each task README states: goal, data inputs, code entry points, output artifacts, status/TODOs
- Shared code stays in `notebooks/` or `scripts/`; task-specific artifacts link to `outputs/`
